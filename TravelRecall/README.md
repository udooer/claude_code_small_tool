# TravelRecall 旅途回憶

用地圖當背景，照時間順序重新走一次旅途。分成兩段：

1. **挑選**：選一個照片 / 影片資料夾，工具會讀出每個檔案的拍攝時間與 GPS 位置，依天分組，讓你勾選要放進回憶的內容。
2. **回憶**：在地圖上照時間播放。路線一段一段畫出來，照片釘在拍攝地點，旁邊顯示照片、時間、地名和你寫的回憶。

不需要安裝。照片只在你自己的瀏覽器裡讀取，**不會上傳**。只有地圖圖磚和地名查詢需要網路。

## 開啟方式

| 方式 | 怎麼做 | 可用的地圖 |
|---|---|---|
| 直接開檔 | 用瀏覽器打開 `index.html` | Esri 街道 / 地形 / 衛星 / 淺灰 / 深色 |
| 本機伺服器 | Windows：點兩下 **`start.cmd`**；macOS / Linux：執行 `./start.sh`。會在本機開一個小伺服器（`http://localhost:8765`）並自動打開瀏覽器，使用時不要關掉那個視窗 | 以上全部，再加 OpenStreetMap |

> OpenStreetMap 會拒絕沒有來源網址的請求（直接開檔就是這樣），所以直接開檔時這個選項會反灰。預設的 Esri 地圖兩種方式都能用。

## 使用方式

### 第一段：挑選照片

- 按「📁 選擇資料夾」，或直接把資料夾拖進視窗。可以分批加入多個資料夾，重複的檔案會自動略過。
- 點一下照片可以切換勾選，標題列的「整天全選 / 取消」可以一次選整天。
- 「✎」幫照片寫一句回憶，播放時會顯示出來。
- 「📍」手動設定位置，適用沒有 GPS 的照片（截圖、相機、關掉定位的手機）。可以在地圖上點選、搜尋地名，或「用前一張的位置」。
- 沒有位置又沒手動設定的照片，播放時會沿用**時間上前一個有位置的地點**（顯示為「約在…」）。沒勾選的照片也會拿來當參考點；如果整趟旅程開頭就沒有位置，才用後一個。
- **影片時間校正**：iPhone 影片有時區資訊，不需要校正。Android 或其他相機拍的影片只記錄 UTC 時間，如果影片排序錯位（例如晚了 8 小時），就在這裡填入時差。
- **匯出行程檔**：把勾選、回憶文字、手動位置存成 `trip_*.json`。下次先「匯入行程檔」，再選同一個資料夾就能還原（依檔名和檔案大小對應）。

### 第二段：地圖回憶

| 操作 | 說明 |
|---|---|
| ▶ / 空白鍵 | 自動播放 / 暫停 |
| ⏭ / → 、 ⏮ / ← | 下一個 / 上一個 |
| 下方膠卷 | 依天分段，點任一張直接跳過去 |
| 地圖上的點 | 點一下跳到那張照片 |
| 速度 | 慢 / 正常 / 快 |
| 影片播完 | 勾選時等影片播完才前進，不勾選時約 8 秒後前進 |
| 地圖樣式 | 街道 / 地形 / 衛星 / 淺灰 / 深色 / OpenStreetMap（會記住上次的選擇） |
| Esc | 回到挑選 |

移動距離超過 30 km（例如換城市）時，地圖會先拉遠讓你看到兩地之間的路線，再飛進目的地。換日時畫面中央會顯示「第 N 天」。

## 支援格式

| 類型 | 格式 | 備註 |
|---|---|---|
| 照片 | JPG、PNG、WebP、HEIC/HEIF | 時間與 GPS 從 EXIF 讀取。HEIC（iPhone 預設格式）在 Safari 直接顯示，Chrome / Edge 則在瀏覽器內自動轉成 JPEG 顯示（每張約 0.5–2 秒，畫面上會先顯示「轉換中…」） |
| 影片 | MP4、MOV、M4V | 從 `moov` 讀取建立時間與 ISO 6709 位置（iPhone、多數 Android 都有）。HEVC 影片在部分瀏覽器可能無法播放 |

沒有拍攝時間的檔案會用檔案修改時間，滑鼠移到縮圖上會顯示提示。

## 檔案結構

```
TravelRecall/
├─ start.cmd    Windows 啟動（呼叫 scripts/Serve.ps1）
├─ start.sh     macOS / Linux 啟動（python3 http.server）
├─ index.html   畫面
├─ style.css
├─ media.js     讀取 EXIF / MP4 中繼資料
├─ app.js       挑選、手動定位、行程檔、地圖播放
└─ lib/         Leaflet 1.9.4（BSD-2）、exifr 7.1.3（MIT）、heic-to 1.6.5（libheif，LGPL-3.0），各附授權檔
```

## 外部服務

- 地圖圖磚：Esri（World Street Map / Topo / Imagery / Light & Dark Gray Canvas）、OpenStreetMap
- 地名搜尋 / 反查：OpenStreetMap Nominatim（每秒最多查詢一次，結果有快取）

只會傳送座標或搜尋文字，不會傳送照片。
